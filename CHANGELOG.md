# Версия 1.1

Тестовый выпуск для проверки на других Windows-компьютерах.

- Красное предупреждение о первых 100 желаниях за день под переключателем
  режимов; оно показывается только с включёнными кликами.
- Уточнена проверка небольшого синего фрагмента фона справа от цифр фонда.
  Текст и крупные значки поверх цифр по-прежнему блокируют чтение.

- При смене правила с включёнными кликами появляется подтверждение.
  Согласие сохраняет и применяет новое правило; отмена возвращает прежнее.

- Готовый Windows-архив со встроенными Python, библиотеками и OCR-моделями.
- Один файл запуска для игроков, без отдельной установки зависимостей.
- Обновлённый компактный интерфейс со светлой и тёмной темами.
- Выбор окон MEmu, LDPlayer и BlueStacks; дополнительные окна для другого фонда.
- Начало кликов по сумме или проценту от прошлого фонда; запас самоцветов.
- Глобальные F8 и F9, растягиваемая история, понятная встроенная инструкция.
- Отчёт об ошибке с версией приложения и необязательными скриншотами в форме.
- Общий фонд для выбранных аккаунтов, фоновые проверки баланса и последние
  исправления пауз во время анимации кнопки и коротких уведомлений.

Известное ограничение: при нескольких эмуляторах возможны задержки нажатий.
Отдельная проверка на Windows без установленного Python пока не завершена.

Режим «С кликами» расходует самоцветы. Выигрыш не гарантирован.
