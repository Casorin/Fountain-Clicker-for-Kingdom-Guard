# Фонтан 1.2 — для Windows

## [Скачать готовую программу для Windows](https://github.com/Casorin/Fountain-Clicker-for-Kingdom-Guard/releases/download/v1.2/Fountain-1.2-Windows.zip)

Python и всё необходимое уже внутри. Ничего отдельно устанавливать не нужно.

## Как Скачать И Запустить

1. Нажмите ссылку «Скачать готовую программу для Windows» выше. Или прокрутите страницу вниз, раскройте **Assets** и нажмите **Fountain-1.2-Windows.zip**.
2. В «Загрузках» нажмите на скачанный архив правой кнопкой мыши → **«Извлечь всё…»** → **«Извлечь»**.
3. Откройте распакованную папку **Fountain-1.2-Windows**.
4. Дважды нажмите **«Запустить Фонтан.exe»** со значком фонтана. Если расширения скрыты, файл называется «Запустить Фонтан».
5. Прочитайте «Первый запуск», выберите окно эмулятора и сначала проверьте показания в режиме **«Без кликов»**.

Не запускайте программу прямо из ZIP и не переносите файл запуска отдельно от папки. **Source code (zip)**, **Source code (tar.gz)** и **.sha256** обычному пользователю не нужны.

## Главное В Версии 1.2

- Улучшено подключение к MEmu, LDPlayer и BlueStacks. В комплект включён общий проверенный ADB; служебные команды запускаются без мигающих окон консоли.
- Выбор эмуляторов стал понятнее: видны процесс загрузки снимков, причины ошибок и подсказки, что сделать дальше. Исправлено повторное открытие окна выбора.
- При первом запуске автоматически открывается инструкция. Действующее правило отдельно показывает сохранённые ограничения, запас самоцветов и скорость кликов.
- Добавлена автоматическая очистка старых технических данных и ограничение истории. Настройки автоматически не удаляются.
- Добавлен полный сброс к первоначальному виду. Исправлены повторная очистка временно занятых папок и автоматический запуск после сброса.

## Обновление С Версии 1.1

Закройте все окна «Фонтана» и распакуйте версию 1.2 в отдельную папку. Если хотите сохранить историю и настройки, скопируйте целиком папку **runtime** из старой папки программы в новую. Старую копию можно оставить как резервную; не запускайте обе версии одновременно.

## Важно

Выпуск доступен для тестирования. Для кликов рекомендуется разрешение эмулятора **1080 × 1080**. Включите локальную отладку ADB в настройках эмулятора. Подробности есть в инструкции программы.

Режим «С кликами» расходует самоцветы. Выигрыш не гарантирован. **F8** запускает или приостанавливает работу, сохраняя режим. **F9** останавливает всё и включает «Без кликов».

Если что-то не работает, нажмите **«Сообщить об ошибке»** в программе. Не отключайте антивирус ради запуска.
