# Фонтан 1.3 — для Windows

## [Скачать готовую программу](https://github.com/Casorin/Fountain-Clicker-for-Kingdom-Guard/releases/download/v1.3/Fountain-1.3-Windows.zip)

Python и необходимые библиотеки уже внутри. Ничего отдельно устанавливать не нужно.

## Как Скачать И Запустить

1. Нажмите ссылку «Скачать готовую программу» выше. Или внизу этой страницы раскройте **Assets** и нажмите **Fountain-1.3-Windows.zip**.
2. Найдите архив в «Загрузках», нажмите правой кнопкой мыши → **«Извлечь всё…»** → **«Извлечь»**.
3. Откройте распакованную папку **Fountain-1.3-Windows** и дважды нажмите **«Запустить Фонтан.exe»** со значком фонтана.
4. Выберите окно эмулятора и сначала проверьте показания в режиме **«Без кликов»**.

Не запускайте программу прямо из ZIP. Не переносите файл запуска отдельно от остальных файлов. **Source code (zip)**, **Source code (tar.gz)** и **.sha256** для запуска не нужны.

## Главное В Версии 1.3

Архив версии 1.3 обновлён 1 ноября 2026 года. Номер версии и ссылка скачивания не изменились. Если вы скачивали его раньше, скачайте архив заново.

- Добавлена поддержка нового оформления события «Ваза желаний со звездой». Исправлено ложное сообщение «Число временно закрыто» из-за синего фона рядом с цифрами.
- Исправление работает и для обычных снимков, и для видеопотока. Сохраняются проверки экрана, кнопки желания, перекрывающих уведомлений и согласованности двух распознавателей.
- Устранено чтение колонн и бликов как лишних цифр рядом с фондом. Это вызывало несовпадение показаний распознавателей и задерживало обнаружение обнуления.
- В историю записывается последнее подтверждённое значение перед падением, а не старый максимум за период. Уже сохранённые записи автоматически не исправляются.

Изменения общие для MEmu, LDPlayer и BlueStacks. Новый фонтан проверен на BlueStacks при **1080 × 1080**, без реальных кликов. Другие разрешения и эмуляторы сначала проверяйте в режиме «Без кликов».

Проверены 20 записанных кадров и автоматические тесты. Несколько полных игровых циклов с этим исправлением ещё не проверены; это не гарантия отсутствия ошибок.

## Как Обновиться

Закройте все окна «Фонтана». Распакуйте версию 1.3 в отдельную папку. Для сохранения истории и настроек скопируйте целиком папку **runtime** из старой папки программы в новую. Не запускайте обе версии одновременно.

Режим «С кликами» расходует самоцветы. Выигрыш не гарантирован. **F8** запускает или приостанавливает работу с сохранением режима. **F9** останавливает всё и включает «Без кликов».

Если что-то не работает, используйте «Сообщить об ошибке» в программе. Не отключайте антивирус ради запуска.
